# Templates

Use these with Obsidian's Templates core plugin or, preferably, through `vault.py new`.
Replace blank IDs with stable lowercase kebab-case values when copying manually. The body
implements the progressive, human-readable contract in
[[90-system/Writing and Documentation Guide|Writing and Documentation Guide]]. Optional
sections may be removed when they do not apply.
